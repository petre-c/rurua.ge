# rurua.ge

ორენოვანი საიტი ნოტარიუს თინათინ რურუასთვის. ქალაქი თბილისი, ალექსანდრე ყაზბეგის გამზირი #6.

## სტრუქტურა

    index.html                 მთავარი გვერდი, ქართული, ძირითადი ენა
    en/index.html              მთავარი გვერდი, ინგლისური
    tarifi/index.html          საზღაურის კალკულატორი, ქართული
    en/fees/index.html         საზღაურის კალკულატორი, ინგლისური
    assets/styles.css          ფერების ცვლადები და განლაგება, ყველა გვერდისთვის
    assets/theme.js            თემის გადამრთველი, წარწერები გვერდის ენით
    assets/fees.js             კალკულატორის განაკვეთები და ლოგიკა
    assets/tinatin-rurua.jpg   პორტრეტი, 760px და @2x 1120px
    assets/favicon.svg         ჩანართის ხატულა

დამოკიდებულებები და აწყობის ეტაპი არ არის. ლოკალურად სანახავად:

    python -m http.server 8765

შემდეგ <http://127.0.0.1:8765/>. ფაილის პირდაპირ გახსნაც მუშაობს, `file://`-ზე მხოლოდ
ენების გადამრთველი ბმულები საჭიროებს დირექტორიის ინდექსს.

## ენები

ქართული ძირითადია და უჭირავს საიტის ფესვი, ინგლისური `/en/`-ში ჯდება. ორივე გვერდზე
`hreflang` ჩანაწერებია, `x-default` ქართულზე მიდის, ანუ საძიებო სისტემა ნაგულისხმევად
ქართულ ვერსიას აჩვენებს. ჰედერის გადამრთველი ორ გვერდს შორის ატარებს.

## თემა

ნაგულისხმევად გვერდი ოპერაციული სისტემის თემას მიჰყვება, `prefers-color-scheme`-ით.
ჰედერის ღილაკი სამ მდგომარეობას ატრიალებს: სისტემური, ნათელი, ბნელი. ხელით არჩეული
ვარიანტი `localStorage`-ში ინახება, სისტემურზე დაბრუნება ჩანაწერს შლის. ატრიბუტს
`<head>`-ში მოთავსებული პატარა სკრიპტი აღადგენს, რომ გვერდი არ აციმციმდეს.

პორტრეტის პანელს ორივე თემაზე მუდმივი ღია ტონი აქვს, რადგან სურათის ფონი თეთრია.
სურათი `mix-blend-mode: multiply`-ით ერევა პანელში, ასე კიდეები არ იკვეთება.

## ვიზიტის ჯავშნა

ჯავშნა cal.com-ზეა, <https://cal.com/rurua/30>. ბმული ორ ადგილას დგას, ჰეროს მთავარ
ღილაკზე და ვიზიტის ბარათში, პლუს JSON-LD-ის `potentialAction`-ში `ReserveAction`-ად.
გარე სერვისია: მისამართის შეცვლისას სამივე ადგილი უნდა განახლდეს ორივე გვერდზე.

## საზღაურის კალკულატორი

კალკულატორი საიტზევეა: `/tarifi/` ქართულად და `/en/fees/` ინგლისურად. ჰეროს დიდი
ღილაკი აქ გადმოდის. ლოგიკა `assets/fees.js`-შია, ოთხი ბლოკი:

    ხელმოწერის ნამდვილობის დამოწმება    გვერდები x პირები x ეგზემპლარები x კოეფიციენტი
    ასლის ნამდვილობის დამოწმება         გვერდები x ეგზემპლარები x კოეფიციენტი
    გარიგების დამოწმება, 23-ე მუხლი     პროგრესული შკალა
    სამკვიდრო მოწმობის გაცემა           იმავე შკალის ნახევარი, თითოეულ წილზე

განაკვეთები ფაილის თავში, `RATES` ობიექტშია. კანონში ცვლილების შემთხვევაში მხოლოდ ის
ერთი ობიექტი უნდა შეიცვალოს, ფორმულებს ხელი არ სჭირდება.

გაანგარიშება ველის შეცვლისთანავე ხდება, ცალკე ღილაკის გარეშე, შედეგი კი დაშლილია:
საზღაური, დამატებითი ხარჯი და დღგ ცალკე ხაზებზე.

HTML და JS განცალკევებულია: ველები და შედეგების ცხრილი მარკაპშია, `fees.js` მხოლოდ
`data-in` და `data-out` ატრიბუტებს კითხულობს. ერთი სკრიპტი ორივე ენას ემსახურება და
თარგმანი კოდში არ ჩანს.

## რუკა

ჰეროს მისამართის რიგში ქინძისთავი, მისამართი და ცალკე ღილაკი „რუკაზე ნახვა" დგას.
ბმული Google-ის ბარათზე გადის cid-ით და არა მისამართის ძებნაზე. იმავე ბმულია
კონტაქტის ბარათში და კალკულატორის გვერდების ფუტერში.

## ონლაინ შეხვედრა

ვიზიტის ბარათში Teams-ის ბმულია, ონლაინ შეხვედრისთვის. ბმული მუდმივი შეხვედრის
ოთახია, ანუ ვინც იცის, ნებისმიერ დროს შეუძლია შესვლა. ამიტომ ტექსტი ხაზს უსვამს, რომ

მონაწილე დაშვებას ელოდოს.

## WhatsApp

ჰეროში, კონტაქტის ბარათში და ფუტერში ერთი და იგივე `wa.me` ბმულია, ნომერზე
995591709931. ბმულს `?text=` პარამეტრით მიმართვის დასაწყისი ერთვის, სადაც წერია, რომ
ადრესატი საიტიდან წერს, ასე ნოტარიუსს თავიდანვე ჩანს, საიდან მოვიდა შეტყობინება.
ინგლისურ გვერდზე იგივე ტექსტი ინგლისურადაა. ტექსტის შეცვლისას ახალი მნიშვნელობა
URL-ისთვის უნდა დაიკოდოს.

ხატულა ერთხელ იწერება SVG `symbol`-ად body-ს დასაწყისში და `<use>`-ით ისმება
სამივე ადგილას.
