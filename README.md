# rurua.ge

ორენოვანი საიტი ნოტარიუს თინათინ რურუასთვის. თბილისი, საბურთალო, ალ. ყაზბეგის გამზირი N6.

## სტრუქტურა

    index.html                 ქართული ვერსია, ძირითადი ენა
    en/index.html              ინგლისური ვერსია
    assets/styles.css          ფერების ცვლადები და განლაგება, ორივე გვერდისთვის
    assets/theme.js            თემის გადამრთველი, წარწერები გვერდის ენით
    assets/tinatin-rurua.jpg   პორტრეტი, 760px და @2x 1120px
    assets/favicon.svg         ჩანართის ხატულა

დამოკიდებულებები და აწყობის ეტაპი არ არის. ლოკალურად სანახავად:

    python -m http.server 8765

შემდეგ <http://127.0.0.1:8765/>. ფაილის პირდაპირ გახსნაც მუშაობს, `file://`-ზე მხოლოდ
ენების გადამრთველი ბმულები საჭიროებს დირექტორიის ინდექსს.

## ენები

ქართული ძირითადია და უჭირავს საიტის ფესვი, ინგლისური `/en/`-ში ჯდება. ორივე გვერდზე
`hreflang` ჩანაწერებია, `x-default` ქართულზე მიდის, ანუ საძიებო სისტემა ნაგულისხმევად
ქართულ ვერსიას აჩვენებს. ჰედერის გადამრთველი ორ გვერდს შორის ატარებს.

## თემა

ნაგულისხმევად გვერდი ოპერაციული სისტემის თემას მიჰყვება, `prefers-color-scheme`-ით.
ჰედერის ღილაკი სამ მდგომარეობას ატრიალებს: სისტემური, ნათელი, ბნელი. ხელით არჩეული
ვარიანტი `localStorage`-ში ინახება, სისტემურზე დაბრუნება ჩანაწერს შლის. ატრიბუტს
`<head>`-ში მოთავსებული პატარა სკრიპტი აღადგენს, რომ გვერდი არ აციმციმდეს.

პორტრეტის პანელს ორივე თემაზე მუდმივი ღია ტონი აქვს, რადგან სურათის ფონი თეთრია.
სურათი `mix-blend-mode: multiply`-ით ერევა პანელში, ასე კიდეები არ იკვეთება.

## WhatsApp

ჰეროში, კონტაქტის ბარათში და ფუტერში ერთი და იგივე `wa.me` ბმულია, ნომერზე
995591709931. ბმულს `?text=` პარამეტრით მიმართვის დასაწყისი ერთვის, სადაც წერია, რომ
ადრესატი საიტიდან წერს, ასე ნოტარიუსს თავიდანვე ჩანს, საიდან მოვიდა შეტყობინება.
ინგლისურ გვერდზე იგივე ტექსტი ინგლისურადაა. ტექსტის შეცვლისას ახალი მნიშვნელობა
URL-ისთვის უნდა დაიკოდოს.

ხატულა ერთხელ იწერება SVG `symbol`-ად body-ს დასაწყისში და `<use>`-ით ისმება
სამივე ადგილას.

## პუბლიკაცია

საიტი GitHub Pages-ზე დგას, `main` ბრანჩის ფესვიდან.

დომენის მიბმა: `CNAME` ფაილი შიგთავსით `rurua.ge`, DNS-ში `A` ჩანაწერები GitHub Pages-ის
მისამართებზე, `www`-სთვის კი `CNAME` ჩანაწერი `petre-c.github.io`-ზე.
